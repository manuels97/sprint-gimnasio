# Sprint Gym

Sitio web del gimnasio Sprint Gym, ubicado en Belgrano R, Buenos Aires.

## Stack

- HTML5
- CSS3
- JavaScript

## Cómo correr el proyecto localmente

Abrí el archivo `index.html` directamente en tu navegador, o usá un servidor local:

```bash
# Con Python
python -m http.server 8000

# Con Node
npx serve
```

## Estructura

```
/
├── index.html                  — Página principal
├── musculacion.html            — Página de Musculación
├── pilates-reformer.html       — Página de Pilates Reformer
├── alto-rendimiento.html       — Página de Alto Rendimiento
├── aerobico.html               — Página de Aeróbico
├── nutricion.html              — Página de Nutrición
├── styles.css                  — Estilos globales
├── service-page.css            — Estilos para páginas de servicio
├── theme-light.css             — Tema claro (preview)
├── script.js                   — Funcionalidad
└── assets/                     — Imágenes, videos y logos
```

## Deploy

Publicado en Netlify. Push a `main` despliega automáticamente.
